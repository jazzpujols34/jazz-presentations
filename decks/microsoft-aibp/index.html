Architecture

Root orchestrator, two agent groups, one safety layer.

Built on Vertex AI + ADK. The orchestration pattern translates directly to Microsoft Agent Framework (MAF) for pro-code, with Copilot Studio + Power Platform as the low-code surface above.
Solution costing

Bottom-up estimate × top-down budget, reconciled.

Bottom-up — usage-driven model

  • Inference — tokens × volume × $/1M (model choice dominates)
  • Orchestration overhead — multi-agent stacks ≈ 2-3× a single LLM call
  • Retrieval — embeddings + vector DB queries
  • Platform — compute, storage, logs, monitoring
  • Licenses — per-seat enterprise AI for internal agent-assist (e.g., Gemini Enterprise for human service teams)
  • Implementation — design, build, change management, training

Top-down — budget-driven constraints

  • Budget envelope — what the client will authorize
  • Status quo baseline — what they pay today for the same outcome (FTE × salary × overhead)
  • Phased rollout — pilot small, prove value, expand. Caps blast radius if assumptions are wrong.
Gap between the two drives model selection, agent count, and phasing — not the other way around.
Value tracked separately — 30-day leading + 90-day business metric, defined in the SOW.
